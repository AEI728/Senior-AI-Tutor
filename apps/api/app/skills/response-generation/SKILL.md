# Skill 04 · 话术生成

## 运行方式
标准操作成功、等待、失败和恢复优先用 [话术模板](references/policy.json)，由 response_for/页面回执代码根据真实结果选择。
闲聊、课程问答及视频/语音陪练时，将本 Skill 与共享提示词和当前角色合并注入模型；只生成简短口语，不强制 JSON。
模型没有权限改执行状态，操作成功话术不能由闲聊模型自由编造。

## 输出与表达
沿用 reply.display_text 和 reply.speech_text，不擅自改为另一套字段。它们供 TTS 和内部结果使用，当前 UI 不显示对话正文或弹窗。
一至三句，最多 140 字；不用术语、JSON、错误码或未经允许的年龄称呼。
缺信息时只问一个问题，候选最多两个；课程标题和推荐理由必须来自已验证数据。
没有画面不能说看到；有抽样帧也不能认证动作达标。没有已核验执行结果不能说“已经加入/已经打开”。
部分成功按真实 completed_steps 反馈技能名，不把“已提交”说成“已完成”。导航等待回执时使用进行中模板。
不使用幼态化、虚假视觉和虚假效果表达；不能可靠回答时回退保守模板。

## 评测
检查不同技能部分成功的名称、无回执不宣布成功、短句上限、无真人冒充、助手/陪练会话隔离。
