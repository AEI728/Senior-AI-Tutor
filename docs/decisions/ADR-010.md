# ADR-010：DeepSeek与能力扩展

日期：2026-11-16。依据：用户要求识别现有DeepSeek配置，并实现除支付外可实现的功能。

本机默认SQLite并读取DeepSeek配置；真实模型无需Docker，preview-local另作显式Mock入口。使用DeepSeek Chat Completions受限函数计划，语音采用其ASR/TTS接口。前端AudioWorklet采集PCM WAV，停顿后自动执行并播报可关闭，播报期间暂停采音避免声音回流，不宣称全双工插话。

扩展四项原创草稿课程和合成流程示意视频。独立本地账号采用PBKDF2密码摘要；正式登录实现OIDC授权码+PKCE、state、nonce和HttpOnly会话cookie，真实供应商仍待配置验收。作品分享须显式确认并经管理员审核；照片去EXIF，举报转回复核。无支付、陌生人私聊或位置匹配。

单张照片反馈不保存原图、不推进进度、不标记动作核验。实时视觉自动推进须另行数据与硬件评估。可选按课程隔离的关键词检索，不声称向量RAG；配置目录不存在时使用内置资料。生产仍需PostgreSQL、OIDC、TLS、内容及隐私签核，不能据本地成功宣称生产就绪。
