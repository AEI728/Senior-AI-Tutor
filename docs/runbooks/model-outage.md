# 模型故障恢复

1. 查看 health/ready 中 provider。该接口只核查配置与数据库，不计为模型可用证明。
2. 确认服务端密钥、额度、模型可用权限；禁止打印 Key 或 Provider 原始异常体。
3. 用户可使用页面按钮加入技能、打开课程与切换步骤；界面显示服务暂不可用。
4. SDK 自动重试为 0。当前单次只产生一个结构化操作计划，服务端白名单执行，避免未知结果盲重试。
5. 客户端网络失败重用同一 client_request_id 重放，已提交的 Turn 返回原结果。
6. UI ACK 超过 90 秒以 UNKNOWN 返回。不得把数据库加入成功当作页面打开成功。
7. 恢复后跑 live-smoke；未验证前不能声称真实模型恢复。不得自动降为 Mock。
