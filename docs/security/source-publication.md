# 源码公开前检查

提交范围为源码、锁文件、原创内部演示素材与脱敏验收资料。真实.env、私钥、运行数据库、数据库备份、上传文件、日志、依赖目录、浏览器跟踪包、测试录音不纳入Git。验收命令中的个人绝对路径使用占位符，保留真实时间与退出码。

提交前运行：

```powershell
./apps/api/.venv/Scripts/python.exe scripts/check_public_source.py --staged
git diff --cached --check
```

检查器扫描实际暂存内容，匹配本地.env中的密钥及常见令牌、私钥格式，只输出文件名和规则名，不输出匹配值。它不替代人工审查或完整的专业秘密扫描。

公开示例中的开发密码、开发JWT密钥和测试凭证均为明确的测试常量，不能用于生产；启动检查会拒绝不安全的生产配置。未来新增账号凭证或测试资料时，需再次检查，不可仅依赖.gitignore。
